# Проекты Димы

Репозиторий для учебных и личных проектов.

## Структура

```
homework/    — домашние задания, учебные материалы
scripts/     — скрипты и утилиты
experiments/ — эксперименты, пробы, идеи
```

## Как работать

Все проекты создаются и обновляются через Claude в Telegram-топике "Дима".
