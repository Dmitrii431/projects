# Резюме: парсер данных начислений ЖКХ (#ИИС, практика)

## Задание

Обработать файл с тестовыми данными и загрузить его в БД. Структуру БД спроектировать по формату файла, СУБД и язык выбрать самостоятельно.
Строки, которые не подходят под формат, в базу не загружать, а выгрузить в отдельный CSV.

Формат строки: лицевой счёт; ФИО; адрес (нас. пункт, улица, дом, квартира/квартиры); период; сумма; затем пары «прибор учёта; показание» (от 0 до n).

## Решение

- Язык: **Python 3**, только стандартная библиотека.
- СУБД: **SQLite**. База хранится в одном файле `data.db` и открывается на любом компьютере без установки сервера, например в DB Browser for SQLite.
- Обработкой занимается отдельный скрипт `parser.py`: он читает файл построчно, проверяет формат, разбирает адрес и показания и загружает готовые значения в базу. Хорошие строки попадают в БД, брак — в `errors.csv` с номером строки и причиной.
- База подстраховывает скрипт своими ограничениями: NOT NULL, UNIQUE, внешние ключи, CHECK на месяц.

## Структура БД

Населённые пункты → улицы → дома → лицевые счета. К счёту привязаны квартиры (отдельная таблица, их может быть несколько), начисления (период и сумма), приборы учёта и их показания.
Всего 8 таблиц, схема лежит в `schema.sql`.

## Что нашлось в тестовом файле

- Кодировка CP1251, 433 416 строк, 43 МБ.
- У правильной строки нечётное число полей (5 + 2n). При чётном числе поля сдвинуты: пропало ФИО или у прибора нет показания. Решено считать такие строки браком.
- Excel испортил часть чисел, превратив их в даты: `май.00`, `мар.00`, `сен.74`.
- Адреса бывают без улицы (`Федоровка д, 81`), без квартиры (`0`), с несколькими квартирами (`80,81,82,83`) и с запятой внутри названия населённого пункта (`Собинка г, Б. Сокольники, ...`). Номер дома парсер находит по виду значения: он начинается с цифры, короткий и без длинных слов.
- Период `519` означает май 2019 (формат ММГГ).

## Результат

- Обработано: 433 416 строк за ~13 секунд.
- В БД загружено 425 612 строк, в брак ушло 7 804.
- Основные причины брака: меньше пяти полей (2711), показание не число (2081), некорректная сумма (1337), пустое ФИО (1218), чётное число полей (445).
