# Парсер файла начислений ЖКХ

Разбирает текстовый файл с начислениями, грузит корректные записи в базу SQLite,
некорректные — в CSV с указанием номера строки и причины.

## Состав

| Файл | Что это |
|---|---|
| `parser.py` | парсер и загрузчик (Python 3, только стандартная библиотека) |
| `schema.sql` | схема базы данных |
| `data.db` | готовая база SQLite с загруженными данными |
| `errors.csv` | отбракованные строки (`;` как разделитель, UTF-8 BOM — открывается в Excel) |

## Запуск

```
python parser.py --input Testovye_dannye.txt --db data.db --errors errors.csv
```

Кодировка исходного файла — CP1251 (меняется ключом `--encoding`).
Полный файл на 433 тысячи строк обрабатывается примерно за 13 секунд.

## Как открыть базу на своём компьютере

База — один файл `data.db` в формате SQLite, сервер устанавливать не нужно.

1. Скачать **DB Browser for SQLite** — https://sqlitebrowser.org/dl/ (есть portable-версия, без установки).
2. Открыть в нём `data.db`.
3. Вкладка «Данные» — таблицы, вкладка «Выполнение SQL» — запросы.

`errors.csv` открывается двойным кликом в Excel.

## Формат строки

```
лицевой счёт ; ФИО ; адрес ; период ; сумма [ ; прибор учёта ; показание ]...
```

Адрес внутри себя разделён запятыми: `населённый пункт, улица, дом, квартира(ы)`.
Улицы может не быть (`Федоровка д, 81`), квартиры может не быть (`0`) или быть
несколько (`Перегрузочная ул, 5а, 80,81,82,83`). Пар «прибор; показание» — от нуля до n.

Пример корректной строки:

```
900046176;К******* **** ;Весь, Полевая, 2, 2;519;654.90;3302320167 СХВ;247.0000;
```

## Правила отбраковки

Строка не попадает в базу, если:

1. не заканчивается символом `;`;
2. полей меньше пяти;
3. число полей чётное — значит пропущено ФИО или у прибора учёта нет показания;
4. лицевой счёт — не число;
5. ФИО пустое или содержит цифры;
6. в адресе меньше двух частей или не найден номер дома;
7. период не вида ММГГ (в файле это `519` — май 2019) или месяц вне 1–12;
8. сумма не вида `1234.56`;
9. название прибора учёта пустое;
10. показание прибора — не число (в файле часто встречается `май.00`, `мар.00` —
    Excel превратил числа в даты).

Номер дома отличается от названия улицы тем, что начинается с цифры, короткий и
не содержит длинных слов: `51-Б`, `13 корп. 3`, `2 б` — дом, `3 Интернационала ул` — улица.

## Схема базы

```
localities (населённые пункты)
    └── streets (улицы)
            └── addresses (дома)
                    └── accounts (лицевые счета: номер, ФИО)
                            ├── account_apartments (квартиры счёта: 0..n)
                            ├── charges (начисления: период + сумма)
                            └── meters (приборы учёта)
                                    └── readings (показания за период)
```

Квартиры вынесены в отдельную таблицу, потому что у одного счёта их может быть
несколько. Показания связаны и с прибором, и с начислением за период.

## Примеры запросов

```sql
-- карточка лицевого счёта
SELECT a.account_number, a.fio, l.name, s.name, ad.house, c.period_raw, c.amount
FROM accounts a
JOIN addresses ad ON ad.id = a.address_id
JOIN localities l ON l.id = ad.locality_id
LEFT JOIN streets s ON s.id = ad.street_id
JOIN charges c ON c.account_id = a.id
WHERE a.account_number = '900046176';

-- показания приборов по счёту
SELECT m.title, r.value
FROM meters m JOIN readings r ON r.meter_id = m.id
WHERE m.account_id = (SELECT id FROM accounts WHERE account_number = '900046176');

-- начисления по населённым пунктам
SELECT l.name, COUNT(*) AS счетов, ROUND(SUM(c.amount), 2) AS сумма
FROM charges c
JOIN accounts a ON a.id = c.account_id
JOIN addresses ad ON ad.id = a.address_id
JOIN localities l ON l.id = ad.locality_id
GROUP BY l.name ORDER BY сумма DESC LIMIT 10;
```
